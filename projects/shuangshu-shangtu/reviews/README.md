# 多AI协作流程
1. 先看指针、Canon、AGENTS、Skill和全64集正文。
2. 只做审稿：GitHub Issue或在独立分支创建 reviews/incoming/<agent>/<issue>.md，不修改母稿。
3. 直接修改：基于最新已合并SHA新建 ai-review/<agent>/<topic> 分支，提出PR，并采用 reviews/REVIEW_TEMPLATE.md。
4. 外部报告台词必须在对应母稿定位。无法定位的主张须作为假设，不得照抄。
5. 主审复核公权/账款/道具/人物/连锁因果，必要时提出REQUEST_CHANGES。
6. 仅维护者/用户批准合并；合并后才创建新版本和更改指针。不得自动宣布SSS或Production Clean。
